# oishijie

把日常里的麻烦，做成顺手的工具。

主要折腾 Android、Windows 效率工具和 Cloudflare 自托管服务，
也用 AI 串起截图识别、信息整理与自动化工作流。

**少一点重复操作，多一点自己掌控。**

[所有仓库](https://github.com/oishijie?tab=repositories) · [联系我](mailto:admin@cro.cc.cd)
